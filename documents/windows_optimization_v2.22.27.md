v2.22.27 - Windows 持久化、计时与故障恢复结构优化

# 实施记录

基线为 2.22.26-render-hotpath。保留现有 UI、动画、JSON schema 和用户工作树改动，依据深度方案渐进替换运行链路。

## 验证边界

审计中的“Windows 原子替换先删除再改名”是条件编译误读：Windows 已使用 MoveFileExW(REPLACE_EXISTING | WRITE_THROUGH)，有问题的是非 Windows 回退。不能将已存在的 Windows 保护当成待修复缺陷。

完整方案还涉及新的服务端协议、本地 IPC、历史重加密、安装升级和外部签名身份。各项必须以代码与测试的实际完成状态交付，不能凭目录拆分或空接口宣称落地。

## 执行顺序

1. 保存快照有界队列和异步回执，验证过期回执、写盘失败、退出屏障。
2. 同一计时投影、有界补算、单调时钟与极值检查。
3. 网络截止、持久任务的歧义状态、恢复核验与冲突可见性。
4. 本地文件边界、危险操作确认、声音反馈与访问树。
5. 回归测试、性能证据与 Windows 构建交付。

具体完成结果和仍需协调的发布条件在验证结束后补充。

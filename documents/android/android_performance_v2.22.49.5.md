# Android 2.22.49.5 性能优化

本次更新减少笔记查询与画布操作中的重复编码、解析和内存分配。Android 版本从 2.22.49.4 增至 2.22.49.5，versionCode 为 22255。Windows 使用独立版本 1.0.3.10。

## 改动

有效笔记、回收站、便签和文档集合直接按当前笔记的删除状态和类型筛选。原路径为了判断删除状态，会把包括计时、风控和历史记录在内的 AppData 编码成 JSON，再交给原生层解析。新路径复用笔记对象，不再为这一判断编码整个账户。

文档、便签先按类型和文件夹筛选，再排序。按更新时间倒序、创建时间倒序排列时，不再提前读取正文来生成所有标题。创建时间正序仍保留同一时间下的标题比较；标题排序、置顶优先及完全相同排序键的稳定顺序保持原有规则。

知识页的回收站数量、置顶数量、待办数量和图片文档数量按笔记变化缓存。查询条件或页面时间刷新不再反复计算这些摘要，回收站计数也不再先排序。

画布完整回复直接从借用的数据编码，减少中间 JSON 对象树。仅平移、缩放视口时返回视口增量，界面核对账户会话、画布标识和基础修订号后，复用既有卡片和连线列表。移动卡片、编辑内容、切换画布等操作继续返回完整画布。

保存仍须通过完整数据校验、旧文件指纹核对、备份和事务落盘。保存失败不会更新界面上的已提交状态，过期或来自其他账户的回复也不会被接受。

## 离线测量

以下结果来自 Windows 主机上的同一组代码与合成数据，不代表手机帧率、峰值内存或整机加速比例。所有内存数值都是一次操作中累计分配的字节数，包含随后释放的临时对象。构建同时进行，磁盘延迟和耗时容易受竞争影响，不据此宣称画布落盘更快。

### 画布

使用前一版保存的真实核心与本版核心，各以 Rust release 构建运行；每次执行真实视口命令并保存文件，30 次采样。数据量为 1000 张卡片、4000 条连线，每张卡片有 700 字节正文。完成后重新打开并核对卡片、连线、视口和修订号。

| 每次视口操作 | 2.22.49.4 | 2.22.49.5 |
| --- | ---: | ---: |
| 平均回复字节数 | 976,849 | 245 |
| 平均内存分配次数 | 42,154 | 105 |
| Rust 平均累计分配字节数 | 10,839,189 | 4,587,087 |

回复体减少约 99.975%，Rust 累计内存分配量减少约 57.68%。这部分测试不包含 Java 对回复的解码，新版界面还省去了视口操作时对全部卡片和连线的再次解码。

### 笔记查询

提取真实生成函数，在 JVM 中执行。样本含 2000 条笔记及 300 条无关历史数据，每项预热 8 次、采样 20 次。旧路径保留序列化步骤，但 JVM 不加载 Android 原生库，因此不计旧路径在手机原生层中的解析开销。

| 每次操作的累计分配量 | 原路径 | 优化后 |
| --- | ---: | ---: |
| 取有效笔记 | 27,287,634 字节 | 22,480 字节 |
| 生成文档排序列表 | 258,862,675 字节 | 50,346 字节 |

各次结果均核对笔记 ID 和顺序。单独检查标题解析回调：2000 条笔记在 UPDATED_DESC 和 CREATED_DESC 模式均为 0 次；CREATED_ASC 和 TITLE_ASC 模式仍为 2000 次。

## 验证记录

已通过共享原生测试 786 项，Rust 源码生成器测试 109 项，打包器测试 61 项，以及 9 组画布持久化和容量场景。原生套件另有 7 项标记为忽略、4 项 Windows 专用测试在 Android 验证中排除；打包器另有 2 项标记为忽略。

Android JVM 共 114 项测试通过，失败、错误、跳过均为 0，其中编辑与业务回归 98 项、画布 12 项、笔记列表 4 项。Lint 错误为 0，警告为 14；按问题标识和消息与前一正式版比较，未新增问题。

隔离变异检查已确认：修改画布默认名称及加密提示文字仍通过；移除旧文件覆盖保护、加密预览保护或笔记删除状态判断，分别使对应业务测试失败。

正式 APK 已完成签名校验、包名与版本核验、16 KiB 对齐检查和三个处理器版本的原生接口检查。与前版签名证书一致，支持覆盖升级。项目根目录、APK 目录、current 目录及构建输出中的交付副本哈希一致。旧正式 APK 已归入 old_apks。

安装包为 `tenfold_v2.22.49.5.apk`，大小 20,061,143 字节。SHA-256：`c50830ad67722cc859e0dce282f8b70c6cb3c7523ea2890bb90bf71c0c5423c7`。Windows 发布文件哈希及修改时间核验通过，仍为 1.0.3.10。

本次未连接手机或运行模拟器，尚无真机帧率、耗电和应用峰值内存测量。

原始记录位于 `release_artifacts/verification/v2.22.49.5/`。其中 `canvas_performance/comparison.json`、`note_performance/acceptance.json` 保留测量数据与源文件摘要；`note_performance/final_source_scope.json` 核对测量函数与最终源码一致；`performance_acceptance.json` 汇总测试及发布后包检查。正式构建前后源码摘要一致。

# 文档默认编辑与主动预览验收

## 实现与状态范围

PR #11基于main提交2527d8bc7c6272d3c20cc9f7c017fa6ad7168d18，原始提交5b6b71a4f125532e33e8130aaf7458c0eea0569b。现有android_document_markdown.rs转换将预览初值改为false，并使用remember(note.id, workspaceKey)，保留主动切换处理器及预览资格条件。没有反复复位的延迟效果或额外焦点操作。

草稿、TextFieldValue、选区与撤销栈继续由DocumentEditorSession持有。已有非空文档不新增强制抢焦点，空白新文档的原标题焦点保留。普通remember不跨编辑器重建保存预览偏好，此行为是本次默认编辑的要求。

## 电脑验证范围

保留入口缺失、重复的失败规格，删除两项新增字符串镜像规格。基线及仅注释变异应通过；移除入口锚点拒绝判断必须使指定失败路径规格失败。最终生成NoteDocumentEditor.kt应使用按文档和工作区记忆的false初值，预览和编辑动作与原正文、保存及焦点流程相接。完整生成链继续保留原段落投影和光标文本块布局。

运行原有33项Markdown领域规格及正式构建入口。实际命令、结果与来源绑定见本轮验证回执，不将静态模式检查称为Compose实际生命周期运行。

## 手机验收范围

分别打开新文档、已有正文、标题或公式文档，默认显示编辑原文。主动预览后保持页面不退出，普通重组及保存状态刷新应保留预览；返回列表重开、换文档、换工作区及系统重建后应重新默认编辑。

切回编辑后检查正文、草稿、组合串、选择、块ID、撤销重做、保存和重新打开。连续换行、键盘边缘光标、文本块上下居中和编辑与预览之间的内容保持均需回归。电脑构建不能代替手机这些交互。

APK沿用原正式签名和包名，候选版本2.23.2.14、内部代码22283，按现有三个位置交付。详见[本版更新说明](../releases/android/release_notes_v2.23.2.14.md)。

# 文档文本块居中与光标避让验收

## 范围和实现

PR #10基于main提交170a2615b7a4e6364a1ac4424e71201c94ca732d，原始提交4e3debe1089524438759d38f0426b48084c1011a。文本装饰区域使用现有52dp最小高度与CenterStart；长文本仍按实际高度增长。转换明确限定在DocumentCanvasBlock的TEXT分支，不修改非文本块和拖拽点。

本机补核并修正光标坐标：BringIntoViewRequester绑定实际innerField的无内边距、无最小高度、无固定宽度包裹层。TextLayoutResult给出的光标矩形与请求目标采用同一局部坐标，文字居中或RTL方向变化后无需猜测偏移。原焦点、布局内容匹配、视口和取消保护继续生效。

原PR的重复锚点测试因缺少精确缩进没有实际构造重复输入。修订为完整锚点重复的状态规格；删除仅检查样式字符串的镜像规格。保留缺失、重复、二次转换和非目标文件透传四类生成器边界，避免锚点漂移后静默漏掉修复。

## 电脑验证

执行项目现有正式构建入口。检查生成的NoteDocumentEditor.kt中修改确实位于TEXT分支，两个锚点都应用，光标布局回调、输入状态和非文本分支保留。UI居中没有引入新的领域逻辑，不编写尺寸或样式镜像单测。原光标、保存、撤销、财务、发送授权和Markdown业务状态规格继续运行。

电脑编译及模板核对不能代替手机实际显示。已有共享Markdown生产代码和离线公式资源若字节未变，可明确引用此前对应来源的验证证据；不能把旧版测试回执改名后称为本次新执行。

## 手机验收

用普通非敏感文档核对单行一级和二级标题、单行正文、两行及长正文、空白块。分别在激活和未激活状态检查上下居中、自然增长和原水平方向，图片、联系人、通话与左侧拖拽点应保持原位置。

键盘打开后，将短块放在视口下沿并移动光标，连续换行、选择和左右移动均应露出当前行。滚动查看其他段落时不得被无关重绘拉回。检查编辑与预览切换、撤销重做、退出保存及重新打开，正文和块ID不得因本次显示调整改变。

本机交付保持正式签名、包名、版本2.23.2.13和内部代码22282，详见[本版更新说明](../releases/android/release_notes_v2.23.2.13.md)。手机验收完成前PR保留待验收。

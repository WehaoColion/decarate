# v2.23.1.2 - 安卓更新说明支持点按复制

本版 versionCode 为 22267。在“我的”页面打开“更新记录”后，点按版本摘要、分组标题或任意一段正文，即可复制对应的完整文字。复制后的内容可以粘贴到便签、聊天或其他应用，中文和标点按原文保留。摘要即使在收起时仅显示两行，点按复制的仍是完整摘要。

每个版本展开后新增“复制本版”按钮。点击后按阅读顺序复制该版本的版本号、日期、摘要、全部分组标题和正文，并保留分组换行，便于一次保存整份更新说明。按钮旁显示“点按文字可复制”，方便发现逐段复制的操作。

复制成功会显示提示；如果系统剪贴板暂时无法访问，会提示复制失败，可以再次尝试。正文的复制操作与版本卡片的展开、收起操作分别响应，仍可通过右侧按钮控制详情。

本次只新增 2.23.1.2 的更新记录。2.23.1.1 和 2.23.1 的记录继续保留，并同样支持逐段复制和复制整版内容。

# v2.23 - 安卓风控核对与法律风险线索

安卓风控把已录账目与经核对的判断分开。收支、现金、资产和负债分别按工作区及月份在本机核对；账目变化后，原核对状态自动失效。缺少资料时，安全可支配金额、健康判断和 30／90 天余额显示“待核对”。旧资产快照中的空负债栏仍为未知，只有明确确认零负债才显示零。预测使用至少三个已核对完整月份，不按月初几天的收入外推整月。已确认但尚未支付的必要周期账单单独预留；疑似重复付款只提示核对，不改动账目。

风控标题旁新增“法律风险线索”。用户先查看本次扫描的资料范围、未覆盖项、接收域名、模型、上传量、预计调用次数与具体内容，再决定是否发送。扫描涵盖当前及归档内容、未删除的历史版本、财务逐笔记录和快照；加密笔记须在本次逐条解锁，附件先核对哈希。报告引用应用内原始记录，列出待核查问题、缺失事实、处理建议和已核对的官方法条来源。报告按工作区加密保存在安卓本机，最多保留五份，可手动删除。分析中断时会标为未完成。

本次只更新安卓客户端。Android 版本名为 2.23，versionCode 为 22264；Windows 客户端、同步服务及其发布文件保持 1.0.3.17。未使用模拟器；实际设备交互尚未经过真机测试。

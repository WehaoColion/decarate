# Android 2.23.2.6 更新说明

版本代码：22275。更新记录时间：2026-10-03 22:48（北京时间）。

## AI 回答显示

修复 AI 回答把 Markdown 和 LaTeX 直接显示为普通文字的问题。独立公式支持 `\[...\]` 和 `$$...$$`，行内公式支持 `\(...\)` 和 `$...$`。乘号、上下标、分数、根号、求和、矩阵等使用安装包内的 KaTeX 和字体排版。标题、加粗、列表、引用、代码和表格同时显示对应格式。

较长的独立公式可横向滚动，回答随外层页面纵向滚动。单条公式无法解析时保留该条公式的原始写法，其余正文继续显示。代码块、行内代码、没有配对的定界符和普通美元金额按原文保留。

新增“复制回答原文”。复制内容与“保存回答为知识页”使用模型返回的原始 Markdown 和 LaTeX，不保存浏览器生成的公式节点。此次改动只处理显示，不生成本机替代答案。

## 保存为知识页后

Markdown 知识页默认以阅读预览打开。点“编辑原文”进入原有正文编辑控件，点“预览公式与排版”查看效果。预览本身不写入文档、更新时间或版本。保存继续保留已有 Markdown 标记，历史版本中的 Markdown 正文也使用同一阅读器。

富文本编辑器、原始正文、附件与版本保存分别保留原有路径，不将数学排版 HTML 写回知识正文。

## 离线显示与安全边界

公式库和 WOFF2 字体随安装包提供，显示过程不向 AI 发起额外请求。模型中的原始 HTML 按文字呈现；远程图片、网页跳转、外部脚本、文件和内容 URI 被阻止。公式阅读器不提供原生 JavaScript 编辑接口，数学命令使用不信任模式和有限宏展开。

每个页面的加载和高度回执绑定当前内容与页面状态。关闭、替换页面或改变宽度后，旧测量不能覆盖当前显示。初始空页的尺寸变化不会被当作公式渲染失败。阅读器出错时保留可选择的回答原文。

本次新增五项 Rust 解析及安全边界规格检查，以及三项页面资源、生命周期和异常尺寸边界检查。变异验证仅改显示颜色继续通过，删除回答 HTML 转义判断必须由安全业务检查明确失败，恢复后继续通过。

合成样例使用本次 Rust 渲染器导出，在本机浏览器按 396 CSS 像素宽度核对浅色和深色显示。两种模式均识别 13 个公式，12 个正常排版，一个故意写错的公式保留原文；分数、根号、求和、矩阵、代码、表格和金额显示均进行了检查。

本次手机未连接，未进行安卓真机或模拟器操作。浏览器样例检查只验证共享 HTML 排版，不代替 Android WebView 的真机交互检查。本次未产生新的付费 AI 调用。

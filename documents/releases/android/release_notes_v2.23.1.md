# v2.23.1 - “我的”页面新增更新记录

本次安卓更新在“我的”页面底部加入“更新记录”卡片。卡片默认收起，并显示应用当前安装版本号，方便先确认版本，再决定是否阅读详细说明。点击“查看”后，页面内直接展开更新记录；阅读完毕可点击“收起”，无需离开“我的”页面。

展开记录时，最新版本的详情默认打开。版本卡片标明版本号、日期和本次更新摘要，说明按主题分段展示。每个版本卡片都有独立的“展开”与“收起”操作；收起某个版本后，仍可看到它的版本号和摘要。总卡片和版本卡片分别控制，长篇说明可以按需查看。展开状态也提供给屏幕阅读器识别。

应用内更新记录从 **2.23.1** 开始。本次只写 2.23.1 的更新内容，不补录以前版本。此后每次安卓正式更新新增当次的中文说明，把新版本放在前面，并保留从本次开始积累的旧条目，供以后逐次查阅。

本次安卓版本名为 **2.23.1**，`versionCode` 为 **22265**。Windows 客户端、同步服务和发布文件的版本保持 **1.0.3.17**。

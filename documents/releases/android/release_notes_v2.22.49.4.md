v2.22.49.4（Android）- 增加触屏知识画布，完善保存、撤销和账户隔离，减少拖动时的内存分配。

从“知识”进入“画布”。可以创建多张画布，把知识页面和独立便签放到同一张画布上，通过有方向的连线整理关系。画布支持重命名、切换、删除、卡片编辑和颜色、两档卡片尺寸、自动排列、适应视图、撤销和重做。

单指拖动卡片或空白处，双指缩放。点击卡片后可编辑便签、打开原页面或建立连线；“卡片”列表可以定位屏幕外的卡片，也提供不依赖画布手势的操作入口。页面卡片只保留页面标识，加密页面显示锁定提示，打开时沿用原有解锁流程。删除卡片不会删除原页面。

画布布局与便签保存在当前账户的本机工作区。普通知识页面继续沿用原有同步；本版画布布局不参与跨设备同步，与当前 Windows 画布的本地保存方式一致。

保存和解析在后台线程进行。手势结束后提交一次修改，保存失败不会提交新状态，文本编辑框会保留草稿。退出画布时先完成已经接收的保存，再释放账户会话。每张画布最多 1000 张卡片、4000 条连线，最多 128 张画布；撤销历史设有容量限制，只保留当前打开会话中的编辑。切换或离开画布会清空撤销记录，删除整张画布不能撤销。

性能调整包括屏幕外卡片跳过绘制、文字排版缓存、页面变化时释放旧预览，以及对未修改画布和卡片数据的共享。1000 张合成卡片的主机测试中，重复 100 次完整卡片复制累计分配 86,789,000 字节，共享复制为 0 字节。此结果验证复制开销，不代表手机帧率或整机内存降幅。

版本号为 2.22.49.4，versionCode 为 22254。Windows 版本保持独立，当前正式版为 1.0.3.10。正式 APK 已更新至项目根目录、APK 目录和 current 发布目录，旧交付包保留在 old_apks 中。

测试限定为本机原生业务测试、JVM 单元测试、正式安卓编译、静态检查、签名及安装包校验。不连接手机，也不运行安卓模拟器。实际触屏手感、软键盘遮挡、设备耗电和厂商后台限制尚未经过真机运行验证。

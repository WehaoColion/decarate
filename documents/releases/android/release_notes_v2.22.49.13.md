# v2.22.49.13 - 键盘弹出时保留便签纸张顶部

便签正文输入时，纸张仍铺到键盘上方，标题、分隔线和正文首行留在可见区域。纸张高度由不可聚焦的容器承担，正文输入框按文字实际高度测量，避免键盘出现后系统为了显示整个高输入框而把标题滚出屏幕。

键盘打开时，版本操作暂时收成细分隔线；关闭键盘后原有版本操作恢复。正文光标位于首行时，滚动位置回到纸张顶部；编辑较长正文时仍按光标位置滚动。顶部导航和便签信息栏在常见屏高下保持可见，六个格式按钮继续以图标在上、文字在下的单排形式显示。

Android 版本从 2.22.49.12 递增至 2.22.49.13，versionCode 为 22263。Windows 保持独立的 1.0.3.16 版本。本次未操作真机，也未启动模拟器；实际键盘显示需在获授权的真机上确认。

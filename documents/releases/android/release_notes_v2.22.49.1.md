# v2.22.49.1 - 修复安卓计时铃声

正式版本为 2.22.49.1，版本代码 22251，包名为 com.ofairyo.gridtimer。安装包为 tenfold_v2.22.49.1.apk，大小 19,836,019 字节。签名证书与 2.22.49 一致，可覆盖安装。

修复了计时阶段更新与铃声监听之间的漏响窗口。启动恢复或状态更新可能已经推进到新的阶段，并消耗原先的阶段切换事件；新的监听会先检查当前阶段，再等待下一次计时边界。若刚刚发生的自动阶段切换仍在有效提醒时间内，可从当前计时段恢复提醒。恢复过程仍检查计时批次、阶段、剩余时间、暂停状态和三秒时效；手动开始、手动继续、已暂停的格子以及过期阶段不会被当作新的自动提醒。系统闹钟和应用监听共用去重保护，同一阶段只接受一次提醒。

内置铃声与备用提示音统一跟随系统闹钟音量，不再使用通知音量。通知栏或通知渠道的发布异常单独处理，避免其异常中断已经开始播放的铃声。两份原始铃声音频与 APK 内的优化资源逐一核对，内容摘要一致。音频用途配置参考 [Android AudioAttributes](https://developer.android.com/reference/android/media/AudioAttributes#USAGE_ALARM)。

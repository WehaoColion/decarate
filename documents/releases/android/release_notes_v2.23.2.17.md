# Android 2.23.2.17

候选版本，内部版本代码 22286。Windows 版本不变。本 PR 不生成或发布 APK，正式发布清单保持原样。

## 本次更新

知识问答增加“任务 Agent”模式。用户先填写目标、选择本次允许读取的未加密知识页，并可查看将发送的资料、接收域名、模型、请求次数和读取上限。点击授权后，使用当前 AI 配置向真实模型接口发起 Responses 函数调用；Rust 侧只开放知识页搜索、分段读取和生成新页草稿三个受限工具。模型不能直接写入、覆盖或删除应用数据。

Agent 会在选定范围内按需搜索和分段读取，生成一份可编辑的新知识页草稿及可选待办，并显示读取来源和工具记录。用户编辑后还须明确点击“确认保存为新知识页”；应用会核验工作区和持久化提交结果，只有确认提交成功才报告保存完成。源页面不会因 Agent 运行而修改。

本次运行限制为最多 30 篇授权页面、单页 100,000 字符、总正文 1,000,000 字符、工具输出累计 32,000 字符、6 次模型请求、16 次工具调用和 210 秒。接口请求设置 `store:false`；自定义服务是否保存请求仍由服务商决定。加密页面、附件、未选中的页面和其它应用数据不进入本功能范围。取消、切换工作区或资料与配置变更后，不再继续后续请求，未完成结果不会作为成功草稿使用。

现有直接问 AI 和知识库问答模式保留。Windows 客户端、同步服务、同步格式和正式 APK 未在本次修改。

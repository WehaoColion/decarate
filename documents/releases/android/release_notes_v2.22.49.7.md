# 2.22.49.7 - 减少画布拖动与连线绘制开销

画布平移和缩放复用已有连线几何数据；拖动卡片时只重算与该卡片相连的线。可见连线合并提交，减少逐条绘制调用。

缩放显示只在整数百分比变化时更新，平移坐标变化不再反复刷新这块文字。绘制卡片时直接使用拖动坐标，普通便签直接传入文本，减少逐帧临时对象。

保留多画布入口、创建上限、保存失败重试、撤销、账户隔离和加密预览保护。连线缓存仅属于当前画布，切换或离开后可回收。

Android 版本由 2.22.49.6 递增至 2.22.49.7，versionCode 为 22257。正式安装包名称：`tenfold_v2.22.49.7.apk`。

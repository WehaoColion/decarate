v1.0.3.17（Windows）- 计时开始与暂停改为后台持久化，减少点击时的窗口卡顿。

Windows 从 1.0.3.16 递增到 1.0.3.17，仅增加第四段。客户端、同步启动器、同步服务和发布清单统一使用 1.0.3.17。Android 正式版维持 2.22.49.13；这次不重新打包 APK。同步协议、账户、数据目录、已配对手机和设备本地计时状态保持兼容。

以前点击计时块的“开始”“暂停”、空格键或托盘“暂停全部”，窗口线程会等待整份状态校验、SQLite 日志和镜像写入。现在操作交给既有的持久化工作线程，按钮即时显示保存状态，写入成功后才更新计时和播放开始铃声。保存中重复点击不会提交相反操作；保存失败时保留上一次已确认的计时状态并显示错误。未保存的格子名称和备注与计时操作一起提交。

切换到计时模块时复用仍有效的笔记缓存，避免无条件重新扫描。同步配置保存失败后的重试时间改用与检查逻辑一致的单调时钟。

验证：Windows 格式与编译检查、客户端 442 项测试通过，24 项按原配置跳过。计时测试覆盖数据库暂时锁定、连点防重、写入失败、草稿保留、空格键和账户替换期间的禁用状态。变异检查中仅修改按钮文案时测试继续通过，临时去掉保存中的重复点击保护时相应测试按预期失败；两处临时改动均已还原。

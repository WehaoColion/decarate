# Windows 1.0.1.1 - 修复手动同步

修复旧版本数据升级时的日志序号检查错误。旧版会因此将工作区置为只读并阻止同步，账户卡片却继续显示上次成功的提示。

隐私记录更新现在会在同一事务中正确推进日志序号；发生写入失败时，记录和序号一起回滚。重复执行不会额外复制数据快照。

账户卡片现在显示当前同步状态和无法启动的原因。同步进行中显示“正在同步…”，完成后恢复“立即同步”；失败不会刷新成功同步时间。

Windows 客户端、同步服务和守护程序已统一更新到 1.0.1.1。Android 保持 2.22.49.1，同步协议和数据格式版本保持兼容。

## 验证

正式发布回归通过 1,141 项，失败 0 项，常规运行跳过 10 项需要专门环境的测试。真实数据副本的启动检查单独通过，44 条笔记及账户身份校验一致。改按钮文案时测试通过，删除关键状态判断时测试失败。

安装前后的本地数据、账户、设置、服务端数据和 Android 安装包一致性检查通过。新版窗口内手动同步已实际触发，观察到执行中状态及成功结果，成功同步时间已更新。后台服务健康检查和登录自启动任务重触发检查通过。

桌面客户端已打开并停在“我的”页面。本次没有执行重启电脑或锁屏测试。

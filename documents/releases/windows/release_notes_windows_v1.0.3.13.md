v1.0.3.13（Windows）- 完善知识画布的多画布管理与大画布操作。

Windows 版本从 1.0.3.12 递增到 1.0.3.13，仅增加第四段。Android 维持 2.22.49.10，正式 APK 不重新打包。同步协议、账户、数据目录和已配对手机保持兼容。

画布顶部直接显示当前名称、全部画布数量与新建入口。全部画布列表显示每张画布的卡片数，可切换、复制当前画布，也可经确认删除。卡片导航可快速定位到当前画布里的任一页面或便签。新建画布自动采用不重复的名称；复制画布保留卡片内容和关系，但为画布、卡片及关系生成新的内部标识。最后一张画布不能删除。画布标题编辑拒绝空白；旧版已经保存的空白标题会在读取时修复，原卡片和连线保留。

连线绘制跳过不可见区域，避免每帧复制整张画布的连线；自动排布改为线性扫描，按卡片尺寸留间距，并在排布后适应视区。画布继续保存在当前 Windows 账户的本机工作区。

验证：画布管理的 5 项回归测试通过，覆盖新建上限、复制后的独立标识、删除回退、保存往返和旧标题修复。删除末张保护的变异使测试失败，单纯修改确认文案不影响测试。Windows 格式与编译检查、完整测试、正式打包和发布校验均通过；发布清单中的三项 Windows EXE 同为 1.0.3.13，Android 2.22.49.10 APK 字节及修改时间保持不变。新版同步守护程序与服务已恢复运行。

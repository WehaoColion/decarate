v1.0.3.15（Windows）- 修复短暂离线后已登录会话过期导致附件清单报错、同步中断的问题。

Windows 从 1.0.3.14 递增到 1.0.3.15，仅增加第四段。客户端、同步启动器、同步服务和发布清单统一使用 1.0.3.15。Android 维持 2.22.49.10，正式 APK 未重新打包；同步协议、账户、数据目录、手机配对和设备本地计时状态规则保持兼容。

此前，Windows 客户端在同步数据前会先读取附件清单。已登录令牌过期时，这一步直接收到 `Login expired`，同步因此中断；界面仍保留账号绑定，用户无法靠重复点击“立即同步”恢复。现在服务端可在原令牌仍有效证明身份、会话此前正常激活并在到期前七天内使用、自然过期不超过 72 小时的条件下，原子续期后继续处理附件清单和数据同步。显式注销、尚未激活、长期闲置或超过恢复期限的令牌仍被拒绝。

验证：Windows 格式与编译检查、完整测试、发布器内置测试、正式打包及独立发布校验均通过。回归测试覆盖附件清单、账户数据下载、已撤销令牌、闲置令牌和超过恢复期限的令牌。测试变异时，仅更改错误提示文字仍通过；暂时删除恢复期限判断则使边界测试失败，随后已还原。发布后，本机真实账号启动同步从附件清单 `Login expired` 恢复为“数据已是最新”，最近同步时间刷新；同步服务健康检查返回 HTTP 200。发布清单记录的三个 Windows EXE 均为 1.0.3.15，Android 2.22.49.10 APK 的 SHA-256 保持 `cc2cff08cc0a30b72c2b4e267c7801069f4efccbfad01af1486a25d5e1f91a12`。

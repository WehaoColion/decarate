# Windows 1.1.0.7

版本 1.1.0.7
更新时间：2026-10-05 00:53

Windows 补齐安卓近期已经使用的 AI 问答流程。在“我的”的 AI 模块提供“直接问 AI”“问知识库”和“法律风险线索”入口；连接设置可选 DeepSeek 官方预设，填写密钥后保存，或发送一次合成文字与图片测试接口能力。不会自动填入密钥，也不会因打开页面而调用付费模型。

“直接问 AI”只发送你的问题，使用模型通用知识与推理；“问知识库”发送问题和相关知识页节选，明确显示所选范围及原文。问题上限为 1000 字，超过上限需要修改，不会静默截断。知识模式最多选择五页，每页最多 900 字，加密和已删除内容不纳入；发送预览可逐页查看本次节选。

点击“预览并发送问题”先核对接收方、模型、正文量和本次请求，点击“确认发送问题”才实际调用接口。授权绑定当前工作区、接口、模型、密钥与问题资料，只能使用一次。取消或改变配置后旧结果不能应用；在途请求结束前不允许重复启动，已发送的请求仍可能计费。

真实远程回答通过 Responses 完成状态检查后显示，没有本机预存答案。AI 回答使用离线 Markdown 与 KaTeX 排版，支持粗体、标题、列表、表格、代码以及行内和独立公式；不加载外网排版脚本，回答中的原始 HTML 不能执行。无法解析的公式保留原文，回答可复制原文或另存为知识页。答案保存为知识页后，普通文本中的行内与独立公式也能在阅读视图中继续排版，编辑和复制保留原文。

风控概览加入明显的“开始 AI 分析”入口。法律资料整理、发送确认、取消和重试操作固定在顶部，长资料与报告单独滚动。空资料、配置缺失、保存未完成或旧快照不会进入发送；确认页重新核对当前快照与配置，一次确认只允许一次发送。失败原因显示在操作旁，可按现状重试。

知识页、金额小数、原有财务核对、计时、账户和资料格式继续保留。客户端、同步服务、同步守护程序和稳定桌面入口统一使用 Windows 1.1.0.7。安卓保持独立版本，不重新打包或改变已交付 APK。

本版更新说明可点按段落复制，也可一次复制完整内容。旧版说明放在“历史版本”入口内，展开后逐版查看；已有记录保留，更新时间按北京时间精确到分钟。

## 验证范围

正式 Windows 构建、相关领域测试、发送授权与取消边界的变异检查已通过；稳定桌面入口已打开显示 1.1.0.7 的实际窗口。本机及公网服务的产品、角色、版本、构建提交与源码快照已按正式清单核对。测试数量与构建信息见[本版验收说明](../../windows/windows_release_verification_v1.1.0.7.md)。

本版未进行真实付费 DeepSeek 调用，未完成全部界面点击和像素排版验收，也未验证手机账户同步、重启、断网恢复和休眠恢复。离线公式使用隔离的合成资料在原生 WebView 中观察到 MathML；这项检查不替代完整界面验收。知识段落中的链接目标或标题若包含数学分隔符，会整段使用原 Markdown 渲染器，以保留原链接。

公开仓库包含本版完整源码和发布元数据。正式 EXE 中仍有本机用户名的编译路径，因此应用安装文件继续仅在本机保留，不公开上传；原发布程序和正式签名材料均保持不变。

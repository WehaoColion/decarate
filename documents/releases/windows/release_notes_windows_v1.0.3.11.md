v1.0.3.11（Windows）- 修复持续使用后仍会失效的同步会话。

Windows 从 1.0.3.10 递增到 1.0.3.11，只增加第四段。客户端、同步服务、同步守护程序和发布清单使用相同版本；Android 保持 2.22.49.8，正式 APK 不重新打包。同步协议、账户、数据目录和手机配对沿用现有状态。

原先登录令牌在签发后固定 30 天失效，即使手机一直在同步也不会续期。过期后手机可以访问电脑的公网服务，却无法通过账号证明，界面会显示“未能通过电脑公网入口与账号校验”。现在有效令牌在剩余不足 15 天时续到未来 30 天。刚过期且最近 7 天内仍在使用的设备，可在到期后 48 小时内通过原令牌的加密证明恢复一次；已撤销、长期闲置或超过恢复窗口的令牌继续要求重新登录。

Windows 客户端、同步守护程序、发布工具和共享库回归测试通过。关键状态测试覆盖有效令牌续期、近期活跃手机的过期恢复、错误证明、长期闲置令牌和已撤销令牌；仅改提示文案时测试通过，放宽近期使用限制时测试失败。正式安装与真机同步结果以发布后验收为准。

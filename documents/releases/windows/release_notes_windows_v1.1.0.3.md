版本号更新为：1.1.0.3，优化 Windows 启动、知识导航、列表和计时缓存，统一桌面入口与应用图标。

# Windows 1.1.0.3 更新内容

## 固定桌面入口

桌面保留固定名称的 TenRate 快捷方式。入口读取正式发布清单，核对最新客户端文件的大小、哈希及发布身份，再启动该版本。后续更新继续使用同一路径，无需重新寻找带版本号的程序。发布后自动修正快捷方式目标及图标，只移除已确认属于当前项目的重复旧快捷方式；其他软件和未知桌面项目保留。

从本版开始，已有窗口会核对新打开请求的版本。同版或更旧版本的请求只激活已有窗口；请求更高版本时，旧窗口先完成已受理的计时操作、编辑草稿与数据库写入，再释放工作区排他锁，新窗口取得锁后才读取资料。保存失败会保留原窗口和草稿，不强制结束进程。无法完成交接会显示处理提示，等待有明确时间上限。更早且不支持交接的旧版仍需从托盘正常退出，再点同一个桌面入口。

## 统一应用图标

使用深青色底、金色数字10与向上箭头，表达记录、专注和积累带来的提升。保留原生矢量源，提供16、24、32、48、64、128和256像素图标。桌面启动器与客户端内嵌相同图标资源，窗口、任务栏和托盘同步使用；快捷方式不再引用历史项目目录中的图标。

## 工作区启动与隐私处理

已有当前格式工作区的首次 SQLite 检查直接执行完整 integrity_check，减少此前先 quick_check 再完整检查的重复扫描。历史审计后仍执行 quick_check，数据库结构、外键、所有者与独立恢复证据继续校验。初始化和格式迁移沿用原流程。

同一个启动事务内，复用已经逐项审计过的所属账户最新快照。如果发生隔离、隐私修复或触发器写入，重新读取并核验最新记录，避免使用写入前的内容。隐私规范化结果只在当前操作内共享，普通保存和恢复镜像减少重复准备；不引入跨操作明文缓存。

## 知识导航与数据库列表

快速跳转复用页面编号及父目录索引，减少大工作区逐页重复查找、字符串整理和排序。查询、访问顺序或笔记内容变化后重新建立结果。加密及已删除页面不显示原始标题，工作区切换和隐私变化会使旧缓存失效。

数据库列表复用与原始记录快照绑定的编号索引和搜索结果。记录排列与原搜索语义保留，临时或外来快照不能误用当前工作区的索引。缓存数量固定，不随查询次数无限增长。

## 计时与编辑响应

计时投影、历史索引及每日统计使用计时资料的内容版本。只修改笔记时保留已有计时读模型，减少界面线程再次解析资料；后台持久化仍按原规则核验。计时、排序、类别、未来元数据以及无法分类的直接变更仍使缓存失效。

点击开始或暂停后，立即显示正在处理。前项自动保存未完成时保留一次计时请求，前项保存成功后继续执行，重复点击不会生成多份操作。开始按首次点击时刻计时，暂停截至点击时刻；只有持久化回执成功后才确认新状态。工作区或原运行身份变化、保存失败时撤销过期请求，并保留编辑草稿。

普通保存复用同一受控会话内的历史审计、父快照与同步元数据，恢复镜像继续核对精确快照及独立恢复证据。同步合并和附件索引写回在后台协调执行；退出期间先完成已接受的本机操作。

## 兼容性与验证

Windows 客户端、配套同步服务、同步启动器及发布文件统一使用1.1.0.3。Android保持2.23.2及其正式APK。账户、资料目录、已配对手机、同步协议和服务数据库格式继续兼容。历史正式发布文件和应用内旧更新说明保留。

性能证据见 documents/windows_deep_optimization_v1.1.0.3.md。不同资料规模、测试程序和测量范围分别记录，不将局部缓存收益写成整机加速，也不将未执行的显式性能测试计作通过。发布状态始终以 release_artifacts/current/release_manifest.json 为准。

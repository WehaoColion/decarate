# Windows 知识模块验收记录

正式版本：2.22.41-knowledge。执行日期：2026 年 9 月 14 日至 15 日。状态：已发布，正式文件验证通过，正常账户的客户端已恢复并打开知识页。

本次测试使用隔离目录和合成文档，覆盖文档编辑与保存、文件夹和筛选、回收站、富文本、加密、知识问答的本地状态，以及 Windows 发布和启动。测试没有编辑正常账户的知识资料。原工作区已有改动保留，未修改 Android 业务代码，未关闭 VPN，未启动安卓模拟器。

## 已复现并修复的问题

| 问题 | 修复后的行为 |
| --- | --- |
| 单独输入斜杠时正文被清空 | 斜杠、前后空格和空行按原输入保存，插入内容使用明确的操作入口 |
| 重新点选当前文档后撤销记录消失 | 保存当前内容后保留撤销、重做和活动文本块 |
| 在文件夹筛选下新建文档却看不到它 | 新文档继承当前文件夹，同时清除会隐藏新文档的搜索和快捷筛选 |
| 回收站沿用旧文件夹和搜索条件，误显为空 | 进入时显示全部已删除知识文档，回收站搜索独立；返回时恢复原查询和文档位置 |
| 恢复文档后仍被旧筛选隐藏 | 恢复时同步确定文件夹，清除快捷筛选并打开文档 |
| 删除文件夹后编辑器仍保留旧归属 | 删除前保存草稿，删除后更新编辑器和撤销记录中的文件夹信息 |
| 彻底删除入口缺少业务状态校验 | 仅允许删除知识回收站中的文档，拒绝活动文档、便签和不存在的编号 |

修复前，新增的问题复现测试出现 7 项预期失败；修复后均通过。新增用例检查业务状态和保存结果，不以具体文案或像素间距作为通过条件。

## 交互与保存

正文前的辅助工具已收起到文档属性、附件、恢复点、导出工具及加密区域。宽窗口中的列表与正文分别滚动，正文获得更多编辑空间。增加搜索清除、筛选清除和文件夹删除确认；没有改动时不能重复保存，文件夹名称为空时不能提交。

新建文档直接接收标题输入，首次保存分配文档编号后保留正文焦点。重新选择正在编辑的文档不会清空撤销历史。富文本属性测试通过实际控件展开和置顶操作，确认标题、置顶状态可以修改，原富文本正文不变。

知识问答在采集来源前保存当前草稿。保存失败时保留草稿，不发起模型请求；打开问答来源前也先完成保存。空问题和正在处理的问题不能重复提交。

原基线为 940 项通过，最终独立 Rust 用例增加 13 项。知识相关定向测试为 17 项通过。默认忽略的 2 项分别为真实 SAPI 语音环境测试和隔离原生数据生成工具；后者已在本轮显式执行。未将真实 SAPI 语音环境记作通过。

控件事件测试覆盖 760×480 和 1240×800 两种窗口尺寸，检查新建输入、首次保存后继续输入、保存按钮禁用、文件夹空名称、加密解锁与锁定，以及写盘故障下的问答阻断。富文本浏览器组件在隔离 Edge 环境中运行，页面网络请求全部阻断；组合输入通过 DOM 事件验证，不能替代真实输入法候选确认。

变异验证两侧均符合预期：只更改搜索文案和布局间距时，定向测试仍通过；禁用彻底删除的业务状态校验时，关键用例失败。变异完成后恢复源码。封存前再次核对 8 个最终修改文件的哈希，富文本内容与布局测试的输入源码也与最终文件一致。

## 正式 EXE 与原生操作

正式 EXE 的 5 组自检全部通过，涵盖计时原子保存、损坏日志恢复、后台任务回执、中文富文本往返，以及跨模块数据保留。正式发布验证命令退出码为 0，5 个发布文件的实际大小和 SHA-256 均符合清单，固定启动入口解析到 2.22.41-knowledge。

通过正式客户端实际完成新建文档、中文标题输入、正文斜杠输入、连续空行、首尾空格、Ctrl+S 保存，以及当前文件夹归属检查。正文以文档块为准逐字比较，不能把用于搜索和摘要的规范化文本当作原始正文。

随后使用 Ctrl+Shift+E 打开内嵌富文本编辑器，并使用 Escape 保存返回。保存后的 HTML 仍保留斜杠、空段和首尾空格。正常退出并重新启动后，使用 Ctrl+F 搜索，再通过 Tab 和 Enter 打开文档，富文本预览正常，磁盘文档结构与退出前一致。两次隔离进程的退出码均为 0。

验收结束后通过固定启动入口恢复正常账户客户端，确认新版本标题、登录状态、知识页以及原先 1 个运行中的计时状态均已显示。

## 发布过程与文件

Windows 独立发布流程现以已发布的 Android 安装包为保留对象，核验正式清单及三份安装包，而不要求 Android 尚未发布的源码版本与其相同。期间发布目录中的 Android 包更新到 2.22.44-knowledge-resume；本轮 Windows 发布保留这一已更新版本，发布前后的三份 APK 哈希、大小和修改时间完全一致。

发布器曾因旧客户端仍在运行而拒绝替换，随后通过正常退出保存草稿再完成发布。本项目同步服务在原子切换后通过固定启动入口恢复，未按进程名称终止其他项目或无法确认路径的进程。

正式客户端位于 release_artifacts/current/grid_timer_windows_client_v2.22.41-knowledge.exe，大小为 15,657,472 字节。固定启动入口位于 release_artifacts/desktop_entry/TenRate_Desktop_Launcher.exe。

## 验证边界

本机窗口截图接口返回 SetIsBorderRequired / 0x80004002，鼠标定位接口返回 coordinate input geometry is unavailable，控件赋值接口也存在 UIA 缓存属性错误。本轮使用键盘操作、控件树、实际磁盘数据及隔离布局测试完成可执行的验收，没有用任意区域截图替代整窗截图，也没有将这些结果记作完整视觉验收。

当前本机未配置知识问答的模型 API Key，因此没有执行外部模型实际生成。真实账户与手机双向同步、完整真实输入法候选确认、真实语音硬件与 SAPI、高 DPI 多屏、长期连续运行未纳入已通过结论。

v1.0.3.12（Windows）- 便签列表与资料库计数性能记录。

## 变更与范围

便签清单统计改用 `str::lines()` 处理 LF 和 CRLF，避免先替换换行符造成整篇正文临时分配。列表摘要逐行读取，在确定超过 52 个 Unicode 字符时停止，保留原有空行、行间空格、后备文字和省略号规则。资料库文件夹计数为当前文件夹建立 ID 索引，保留重复 ID 时先出现的文件夹名称。

## 隔离测量

同一 Windows MSVC debug 测试配置、同一合成夹具及 `note_list_cache_performance_benchmark` 范围，前后各执行 40 次。指标是测试线程每次操作累计请求的堆字节，不是进程常驻内存。该探针只测显示行构造、排序和释放，不测搜索、egui 绘制、GPU、磁盘或同步。

| 合成规模 | 修改前申请字节/次 | 修改后申请字节/次 | 减少 |
| --- | ---: | ---: | ---: |
| 44 页，每页 2 块 | 222,219 | 127,287 | 42.7% |
| 129 页，每页 8 块 | 4,357,635 | 2,226,362 | 48.9% |

资料库文件夹计数的单次独立探针使用 12,000 篇文档和 512 个文件夹。原始逐项扫描耗时 69.404 毫秒，建立索引后耗时 15.491 毫秒。该探针不测文档行的界面绘制，不应换算为整体帧率。

## 正确性边界

定向测试覆盖列表缓存失效、加密内容不进入搜索结果与显示行、解锁后重新锁定、正文与恢复记录选择、LF/CRLF 清单、Unicode 摘要边界、重复文件夹 ID 的首项优先规则，以及无效文件夹 ID 归入“未入库”。变异检查中，单改筛选按钮文案时文件夹规则测试仍通过；把首项优先改为末项覆盖时，该测试失败。变异文件已按哈希恢复。

正式打包的格式闸门、共享库测试、客户端测试、同步守护程序测试、发布工具测试、可执行文件完整性链和服务运行检查均通过。打包后的 `tools/windows.ps1 verify` 独立校验通过，发布清单中的五个文件均按大小与 SHA-256 再次核对成功。

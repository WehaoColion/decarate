# 知识工作区升级与验收清单

## 目标

对照 FlowUs，把当前平铺文档和简单文本块升级为可组织页面、编辑结构化内容、管理数据库记录、建立引用和复用资料的完整知识工作区。最终交付包括正式 Windows 程序、必要的安卓数据读取兼容、迁移与同步测试、真实窗口验收及使用说明。完成状态必须依据最终源码、可执行程序和实际操作，不能依据菜单数量或测试数量代替能力验收。

升级前基线为 Windows 2.22.51-windows-audit、Android 2.22.46-device-timers，AppData schema 15。原有加密、撤销重做、只读版本、回收站、账户隔离和设备独立计时继续保留。

## 实施原则

共享数据结构和规则使用 Rust。页面属性保存在受版本与加密保护的文档结构内，数据库记录继续使用独立页面 ID，避免把所有记录塞成无法独立合并的一段文本。高级结构必须有显式版本和校验，旧编辑器兼容不能依赖隐藏字符串或未经校验的 JSON。

界面展示真实业务能力，功能未实现时不能用静态卡片或无效按钮充数。基于已有账户同步逐步完善个人知识工作流；FlowUs 的商业套餐、企业组织管理与服务运营属于对照背景，不等同于本应用需要复制的产品业务。

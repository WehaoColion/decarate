# 知识工作区使用说明

## 页面与资料组织

从“知识”进入工作区。页面树可建立多级子页面，正文上方的面包屑可返回父页面。“页面属性”中可设置图标、色彩封面、标签、通栏和小字号，也可调整父页面、收藏页面或将当前页保存为模板。

编辑时，搜索框位于页面树上方。“返回文档列表”可展开完整的列表与筛选设置。

页面树支持拖动调整父级，右键菜单可把页面放到同级最前或最后。系统会阻止循环父子关系。删除的页面可从回收站恢复；页面历史属于页面内部的恢复工具，主导航仍为“计时、便签、知识、风控、我的”。

## 编辑内容块

“＋ 内容块”可插入标题、段落、列表、待办、引用、提示块、折叠块、分隔线、代码、公式、表格、分栏、页面引用、目录、图片及文件等内容。在文本块内输入 / 可打开块类型菜单。按 Ctrl+Enter 在当前块后继续添加内容。

块左侧六个圆点用于拖动排序。右键可转换类型、调整颜色、复制块、删除块及子内容、复制块引用和添加批注。分栏可分别添加内容，收缩栏数时会把原有子内容移到保留的栏中。表格可增减行列，并设置标题行。编号列表按同层连续内容重新编号。

公式块使用 LaTeX 输入，例如 `\frac{1}{3}`。“预览”或“阅读视图”使用内置离线公式资源显示排版结果。代码块可设置语言并复制代码。已有富文本资料仍使用原来的编辑方式；具有高级块结构的页面会进入结构化编辑器。

## 数据库与七种视图

“＋ 数据库”建立记录集合。每条记录也是一张可打开、继续写正文的页面。可配置文本、数字、单选、多选、状态、日期、复选框、链接、关联、公式和汇总等属性。

同一批记录可切换表格、看板、列表、画廊、日历、时间轴和表单。“视图设置”用于设置显示属性、分组、筛选、排序和统计，并保存为视图配置。日历和时间轴需要选择日期属性；看板需要选择适合分组的属性。看板拖动会修改记录的分组属性。表单必填字段未完成时，提交按钮不可用。

属性可以隐藏并恢复，隐藏不删除已有记录值。收到另一端的修改后，未编辑的单元格会刷新；正在输入的单元格保留本地草稿，避免同步打断输入。

## 引用、模板与查找

页面引用块和块引用可跳转到目标内容。文本内支持 [[页面ID]] 和 [[页面ID#块ID|显示文字]]；可通过“复制块引用”取得准确格式。页面下方显示引用关系，标题目录可定位对应内容。搜索覆盖正文、标签和属性值，并显示命中片段；未解锁的加密正文不进入搜索。

内置模板包括项目、会议、阅读、阶段复盘和任务管理。项目、会议与复盘模板会同时创建相关行动项数据库。自定义页面可标记为模板。复制页面及子页面时，系统会重新生成页面与块的 ID，并重建复制范围内的引用。

## 文件与资料迁移

文件、音频和视频块可通过“选择本地文件”导入，并从“另存为”导出。文件实际内容与页面引用一起保存，导入失败会保留原有页面。单个附件上限为 16 MiB。加密页面暂不支持外部附件。

可导入 Markdown、CSV 和工作区 JSON，导出 Markdown、HTML、CSV 和工作区 JSON。Markdown 适合通用文字交换，CSV 适合数据库记录；保留完整页面层级、属性、块和本地附件时，使用工作区 JSON。导入时会先检查格式、引用、附件大小和哈希，检查失败不提交部分页面。HTML 导出会内嵌所需附件和公式资源。

## 保存、锁定与恢复

标题旁显示保存状态。保存失败时会保留草稿，可修正问题后重试。页面锁定后，内容修改和记录提交被禁用，阅读和引用跳转仍可使用。

页面历史支持命名版本、恢复点和差异查看。恢复前先查看所选版本与当前页的变化。恢复只处理目标页面，并保留当前计时和风控数据。旧客户端传回缺少高级结构的普通文本时，系统保留高级页面，并将旧端修改保存为“旧版编辑器的修改”，供手动查看和恢复。

## 手机与电脑配合

本次 Windows 版本为 2.22.52-knowledge-workspace，配套 Android 版本为 2.22.47-knowledge-format。Android 可以读取新页面的结构化内容，并阻止旧的普通编辑入口清掉高级结构；高级块和数据库配置在 Windows 端编辑。Android 的公式暂以公式文本展示，文件及音视频显示附件信息。

同步会传递资料内容。计时开始、暂停和结束仍属于当前设备：手机上的同一个块开始计时，不会让电脑也自动启动或响铃；电脑操作也不会替手机启停。两台设备可以分别操作自己的计时器。
